# 全链路验收与生产切换

## Goal

完成 V1 全业务链路、权限、安全、迁移和移动/桌面体验验收，并安全切换到飞书标准化新表。

## Requirements

- 覆盖所有角色、两仓、三类领用、混领、归还、调拨、盘点、提醒、查询、导出和同步异常。
- 完成生产域名、OAuth 回调、首位管理员、密钥、备份、监控和部署配置。
- 14 个产品真实主图齐全后才能完成产品图片与正式上线验收。
- 切换前短时冻结旧表写入、最终增量迁移和零差异对账；失败按文档回滚。

## Acceptance Criteria

- [ ] 全量 lint、typecheck、unit、integration、E2E、build 和安全检查通过。
- [ ] Playwright 在移动和桌面完成主要业务流程视觉/交互验收。
- [ ] 迁移后飞书定向回读与本地对账为零差异。
- [ ] 部署、管理员操作、迁移、对账和回滚文档完整。
- [ ] 未满足主图或零差异条件时不得宣布正式上线完成。

## Dependencies

- 前置：其余八个子任务全部完成。
