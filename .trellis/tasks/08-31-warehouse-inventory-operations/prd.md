# 归还、调拨、盘点与提醒

## Goal

补齐领用以外的库存变化和管理员跟进闭环，确保所有数量变化都有流水。

## Requirements

- 入库、实物归还、双仓调拨、盘盈/盘亏统一走库存事务服务。
- 到期或离职只创建待归还任务，管理员确认实物回库后才增加库存。
- 调拨一出一入且总量守恒，操作人需拥有两仓权限或为系统管理员。
- 工作日历可配置节假日和调休；提醒仅进入管理员任务中心。

## Acceptance Criteria

- [ ] 不存在无流水修改余额入口。
- [ ] 日期到达或离职不会自动入库。
- [ ] 调拨、归还和盘点重复请求均幂等。
- [ ] 管理员任务按仓库授权过滤。

## Dependencies

- 前置：正常、临时与线下流程。
- 后续：解锁飞书同步与迁移。
