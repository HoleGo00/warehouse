# 独立账号扫码注册方案

记录日期：2026-08-28

> 状态：已废弃。后续产品决策取消了本地注册和密码登录，V1 仅使用公司飞书登录，公司应用范围内员工首次登录自动进入系统且无需管理员审核。本文件仅保留决策历史。

## 用户填写字段

### 必填

| 字段 | 用途与规则 |
| --- | --- |
| 真实姓名 | 用于管理员核验、领用单展示和审计快照 |
| 手机号 | 推荐同时作为登录账号；全系统唯一 |
| 所属部门 | 用于管理员核验和后续查询 |
| 登录密码 | 不少于 8 位，至少包含字母和数字 |
| 确认密码 | 必须与登录密码一致 |

### 可选

| 字段 | 用途与规则 |
| --- | --- |
| 职务/岗位 | 辅助管理员核验身份，不作为权限来源 |
| 员工编号 | 公司有统一工号体系时建议改为必填；填写后全系统唯一 |

## 系统自动记录字段

| 字段 | 用途与规则 |
| --- | --- |
| 注册来源仓库 | 根据西湖仓或余杭仓二维码自动写入，仅用于审计，不代表仓库权限 |
| 注册来源二维码 | 记录具体二维码入口版本或标识 |
| 注册时间 | 服务器生成 |
| 账号状态 | 待审核、正常、已拒绝、已停用 |
| 申请角色 | 自助注册固定为普通领用人，前端不可修改 |
| 审核人/审核时间 | 系统管理员操作后生成 |
| 审核意见/拒绝原因 | 拒绝或退回修改时必填 |
| 最近登录时间 | 用于账号安全审计 |

## 注册流程

1. 扫描仓库二维码。
2. 未登录用户选择注册。
3. 填写资料并提交，账号进入待审核。
4. 待审核账号不能提交正常或临时领用，只能查看审核状态。
5. 系统管理员批准后账号生效；拒绝时必须填写原因。
6. 用户可按拒绝原因修改资料并重新提交。

## 安全约束

- 自助注册只能创建普通领用人，角色字段由后端强制写入。
- 手机号唯一；员工编号填写时唯一。
- 密码使用强密码哈希保存，不记录或展示明文。
- 注册来源仓库不自动转化为仓库数据权限。
