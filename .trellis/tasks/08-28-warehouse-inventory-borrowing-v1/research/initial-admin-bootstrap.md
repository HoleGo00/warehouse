# 首位系统管理员初始化

记录日期：2026-08-28

## 已确认方案

- 部署配置预设一名公司飞书员工的稳定用户标识和公司租户标识。
- 系统尚无系统管理员时，该员工首次成功登录自动获得系统管理员角色。
- 不使用姓名作为初始化匹配条件。
- 初始化过程写入审计日志，包括用户、租户、时间和配置版本。
- 一旦系统中已有系统管理员，自动初始化逻辑永久停止授予权限。
- 后续仓库管理员、仓库范围和其他系统管理员均由已有系统管理员在后台配置。

## 推荐配置

- `INITIAL_ADMIN_FEISHU_USER_ID`
- `FEISHU_ALLOWED_TENANT_KEY`

两个配置必须同时匹配。实际环境变量名称可在技术设计阶段按项目配置规范调整。

## 安全约束

- 首位管理员创建与角色授予在同一数据库事务中完成，避免并发首次登录产生多名管理员。
- 初始化成功后记录不可修改的审计事件。
- 后续修改环境变量不得为其他员工自动提权。
- 不能使用姓名、头像或部门等可重复信息进行匹配。
