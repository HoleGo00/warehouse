# 业务查询、Excel 导出与管理后台

## Goal

提供管理员日常查询、双工作表导出、权限配置、工作日历、同步异常和对账处理界面。

## Requirements

- 按日期、仓库、领用人、商品、尺码、类型、状态和最终去向组合查询。
- 单据详情展示明细、审核、发放、归还和库存流水。
- Excel 固定包含 `领用单汇总` 与 `商品明细`，共享筛选范围和业务单号。
- 系统管理员维护角色、仓库授权、商品图片、日历、飞书映射和同步重试。

## Acceptance Criteria

- [ ] 混领单在汇总一行、明细多行且数量可核对。
- [ ] 仓库管理员查询和导出不能越过授权仓库。
- [ ] 人工重试复用原幂等键并留下审计。
- [ ] 大数据量导出不会阻塞普通 API 请求。

## Dependencies

- 前置：工程、权限、全部业务流程和飞书同步。
- 后续：解锁最终全链路验收。
