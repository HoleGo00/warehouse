# 正常领用审核与发放

## Goal

完成正常领用从扫码填写、整单提交、一道审核预占到确认发放的完整闭环。

## Requirements

- 同仓单据可混合指环和腕表，主单信息统一。
- 提交校验库存，审核再次校验并整单预占；任一明细失败整单退回。
- 只有确认发放才创建库存负流水；发放前取消释放全部预占。
- 内部领用、赠送、销售、展品及归还条件按 Epic PRD 校验。
- 审核、退回、取消和发放均留操作人、时间、意见和审计。

## Acceptance Criteria

- [ ] 不支持部分审核、部分预占或部分发放。
- [ ] 审核前不扣库存，批准后可用库存反映预占，发放后生成流水。
- [ ] 并发审核不能超卖，重复发放不能产生第二次流水。
- [ ] 越权仓库管理员无法查看或处理单据。

## Dependencies

- 前置：工程、登录权限、商品库存二维码。
- 后续：解锁临时领用与线下登记。
