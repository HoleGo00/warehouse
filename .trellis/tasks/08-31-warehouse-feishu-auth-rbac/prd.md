# 飞书登录与仓库权限

## Goal

实现公司飞书唯一登录、首位系统管理员初始化、三角色和仓库级授权，为全部后续业务接口提供可信身份与权限边界。

## Requirements

- 普通浏览器 OAuth 与飞书客户端免登识别为同一本地用户；无本地密码或注册审核。
- 校验公司 tenant、应用可用范围和在职状态；首次登录默认普通领用人。
- 首位系统管理员按稳定飞书用户 ID + tenant 一次性初始化。
- 仓库管理员可授权西湖、余杭或两仓；系统管理员默认全仓。
- 所有仓库 API 服务端校验权限并记录审计。
- 离职/停用用户不能建立新会话，历史身份快照保留。

## Acceptance Criteria

- [ ] 外租户、无应用权限或停用员工登录被拒绝。
- [ ] 首位管理员并发首次登录只产生一个初始化结果。
- [ ] 普通员工、单仓管理员、双仓管理员、系统管理员权限矩阵通过。
- [ ] OAuth 回跳保留二维码仓库上下文且不能跳转外部地址。
- [ ] 不调用 `lark-cli` 处理登录或权限认证。
