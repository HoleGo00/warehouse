# 临时领用与线下登记

## Goal

实现来不及提前审批时的临时领用，以及仓库管理员对已发生现场领取的完整代录。

## Requirements

- 临时领用只需当前领用人、二维码仓库和商品明细，提交即整单扣减并进入待补手续。
- 截止时间为提交日之后第三个工作日 23:59:59，超期标红但不冻结用户。
- 补齐资料后一道审核；不合格退回补正，不撤销既有出库且不再次扣库存。
- 线下登记必须完整，由授权仓库管理员直接整单出库；不完整时必须走临时领用。

## Acceptance Criteria

- [ ] 临时领用任一明细不足时整单失败。
- [ ] 后补审核不会产生第二次流水。
- [ ] 超期状态和管理员任务按工作日历准确计算。
- [ ] 线下登记保留实际领用人与代录管理员。

## Dependencies

- 前置：正常领用核心能力。
- 后续：解锁库存操作与提醒。
