# 飞书库存同步与历史迁移

## Goal

通过官方 `lark-cli` 将本地库存事实可靠同步到两套 Base，并创建标准化新表、迁移和核对全部历史库存。

## Requirements

- worker 使用 PostgreSQL outbox、幂等键、重试和人工处理状态调用 `lark-cli`。
- 两套 Base 各新增产品、余额、流水 V1 表，不删除、不重命名旧表字段。
- 指环和腕表混领分别同步，主单允许部分同步状态但最终必须全部成功。
- 691 条源记录按已确认规则迁移；空白零值记录只进异常报告。
- 全部历史库存归余杭仓，西湖仓为零；三个历史腕表独立迁移。
- 迁移可重复执行，旧表切换后只读保留。

## Acceptance Criteria

- [ ] 指环 2,984 入 / 828 出 / 2,156 余额零差异。
- [ ] 腕表 326 入 / 61 出 / 265 余额零差异，历史腕表分别 27 / 42 / 68。
- [ ] 同一迁移批次复跑新增零记录。
- [ ] CLI 超时、重启和人工重试不重复流水或余额变化。
- [ ] 真实写入前完成测试 Base 和正式 dry-run 报告。

## Dependencies

- 前置：前六个业务子任务全部完成。
- 后续：解锁查询导出后台和最终切换。
